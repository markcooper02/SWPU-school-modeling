# SWPU-school-modeling
一个**单文件、零外部运行依赖**的校园三维可视化页面：使用原生 **WebGL2 + JavaScript + CSS** 程序化生成西南石油大学成都校区的示意性空间模型，支持建筑导览、实时光影调节、相机漫游与视图导出。

> 交付文件：[`swpu-chengdu-campus-3d.html`](./swpu-chengdu-campus-3d.html)
> 直接用浏览器打开即可运行，无需安装、无需构建、无需联网。

***

## 1. 快速开始

### 方式一：直接打开

双击 `swpu-chengdu-campus-3d.html`，或使用浏览器打开该文件。

### 方式二：本地静态服务（可选）

```bash
# 任选一种静态服务器
python3 -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080/swpu-chengdu-campus-3d.html`。

### 浏览器要求

* 推荐：近期版本的 Chrome / Edge / Firefox / Safari，并开启硬件加速。

* 需要 **WebGL2** 才能获得完整三维效果。

* 若 WebGL2 不可用，页面会自动降级为**可交互平面导览**，建筑列表、搜索与详情仍可使用。

## 2. 功能概览

### 校园空间

* 南门核心区：南大门、创业广场、图书馆总馆、思学楼、行政楼、博学楼等。

* 教学科研区：明德楼、明志楼、明辨楼、明理楼及 C 区、图书馆分馆、本科综合实验楼等。

* 运动生活区：学生活动中心、创新创业及新能源研发中心、食堂、体育馆、田径场、游泳池、球场、学生公寓组团。

* 实训科研区：逸夫工程训练中心、天然气水合物实验室、科研实验中心、后勤楼等。

* 环境要素：校园道路骨架、水系与 pond、桥梁、广场铺装、路灯、围墙、树木、动态人车、能源主题雕塑与抽油机示意装置。

### 导览交互

* 建筑搜索：按名称、编号、英文或关键词过滤。

* 分类筛选：教学科研 / 公共服务 / 生活公寓 / 运动场馆。

* 点选建筑：三维场景、标注或列表均可选中，查看详情并聚焦。

* 视角模式：三维全景 / 平面总览 / 南门视角。

* 指北针、示意比例尺、状态栏（渲染模式、三角面、帧率、相机参数）。

* 标注自动避让：缩放较远或屏幕较窄时优先保留关键地标，减少重叠。

## 4. 渲染与技术实现

* **渲染 API**：原生 WebGL2，无 Three.js、无 CDN、无外部脚本/样式/字体/贴图请求。

* **几何生成**：程序化盒体、圆柱、低多边形球、道路 ribbon、椭圆广场、跑道环、水系 Catmull-Rom 采样、建筑立面窗格、女儿墙、入口雨棚、拱形屋面等。

* **实例化**：树木、车辆、行人使用 instanced drawing，降低 draw call。

* **光照**：方向光 + 半球环境光 + 高光/菲涅尔；夜间窗灯与路灯自发光。

* **阴影**：深度贴图 + PCF 软化；太阳高度、建筑高度、绿化密度变化时按需重烘焙。

* **环境遮蔽**：Canvas 2D 预烘焙建筑/道路接触 AO 纹理。

* **后处理**：亮部提取 → 半分辨率双向高斯模糊 → Bloom 合成 → 色调映射、饱和度、暗角与颗粒。

* ** atmosphere **：天空渐变、太阳辉光、夜间星点、距离雾、漂移粒子。

* **动画**：水面波纹、树木风动、人车路径运动、抽油机游梁摆动。

* **拾取**：CPU 射线-AABB 检测，支持悬停与点选。

* **相机**：阻尼环绕/缩放/平移，支持聚焦建筑与预设视角。

* **降级**：WebGL2 不可用时生成 SVG 平面导览；图形上下文丢失后尝试自动恢复。

* **无障碍/动效**：遵循 `prefers-reduced-motion`，关闭自动环绕、粒子与风动等强动效。

### 性能参考

* 场景约 **9.4 万三角面**（含实例化树木与人车估算）。

* 阴影贴图：桌面 1024²，移动端 512²。

* 渲染分辨率 DPR 上限 1.6；Bloom 使用半分辨率目标。

* 软件渲染（如 SwiftShader）可运行但帧率较低，建议使用硬件 GPU 浏览。

## 6. 项目结构

```text
.
├── swpu-chengdu-campus-3d.html   # 最终交付：单文件离线页面
├── README.md
├── build.mjs                     # 将 src 内联合并为单文件 HTML
├── src/
│   ├── index.html                # 页面骨架、内联 SVG 图标、弹窗
│   ├── style.css                 # 全部样式
│   ├── data.js                   # 建筑/道路/水系/分区等布局数据
│   ├── geometry.js               # 数学库与程序化几何生成
│   ├── engine.js                 # WebGL2 着色器、渲染管线、拾取
│   └── ui.js                     # 控件、列表、标注、导出、主循环
├── package.json                  # 仅可选自动化验收依赖
├── test.mjs / qa.mjs / mob.mjs   # 可选 Playwright 验收脚本
└── *.png                         # 验收/预览截图（非运行必需）
```

### 重新构建单文件

修改 `src/` 后执行：

```bash
node build.mjs
```

生成/覆盖 `swpu-chengdu-campus-3d.html`。构建脚本只使用 Node.js 内置 `fs`，无第三方构建依赖。

### 可选自动化验收

运行页面本身**不需要**安装任何依赖。若需复现浏览器验收：

```bash
npm install
npx playwright install chromium
# Linux 如缺少系统库，可执行：
# npx playwright install-deps chromium

node test.mjs   # 基础渲染与控制台错误检查
node qa.mjs     # 交互、导出、移动端、降级等综合检查
node mob.mjs    # 移动端布局检查
```

验收脚本使用 SwiftShader 软件渲染参数，耗时可能较长；这不影响最终 HTML 在真实 GPU 浏览器中的运行。

## 7. 常见问题

**Q：打开后只有平面导览？**
A：当前浏览器或环境未启用 WebGL2。请开启硬件加速、更新浏览器，或换用 Chrome / Edge / Firefox。平面导览仍可搜索和查看建筑。

**Q：画面卡顿？**
A：降低绿化密度、关闭柔和阴影/动态人车/光晕，或缩小窗口。软件渲染环境帧率偏低属正常现象。

**Q：标注变少了？**
A：标注会自动避让，远景或小屏优先保留关键地标。拉近视角或选中建筑可显示更多细节。

**Q：导出 PNG 没有反应？**
A：请允许浏览器下载；导出会先渲染当前帧再合成标题栏。若处于降级平面模式，则导出 SVG。

**Q：是否会产生网络请求？**
A：运行所需资源全部内联，不加载外部脚本、样式、字体或贴图。仅当用户主动点击「说明 / 来源」中的外部链接时才会打开对应网站。

**Q：可以嵌入到其他页面吗？**
A：可以。将 HTML 作为独立页面部署，或通过 iframe 嵌入；请确保目标环境允许 WebGL2 与脚本执行。
